# AeroLearn v6.4 — Student Attendance Visibility

- Adds a student-only attendance endpoint scoped to the authenticated student and selected course.
- Student responses contain only that student's own attendance row/status; classmates are never returned.
- Course Workspace attendance count now uses the student's actual recorded sessions.
- Attendance tab shows Week, Period, Date and the logged-in student's Present/Absent/Late status.
- Supports canonical User-to-Student linkage plus legacy studentId/email identity fallback.
- Keeps all v6.3 course consistency and v6.2 attendance management fixes.
