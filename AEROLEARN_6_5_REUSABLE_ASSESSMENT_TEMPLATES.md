# AeroLearn v6.5 — Reusable Assessment Templates
- Adds reusable Assessment Type library for Admin and Instructor.
- Each type contains customizable Quiz/Assignment/Lab/Project/Mid/Final components and must total exactly 100%.
- A saved type can be assigned to any course the instructor owns (Admin can assign to any course).
- Assignment creates an independent course assessment plan; later template deletion does not alter existing course marks.
- Existing assessments and scores remain untouched.
- Custom one-off assessment creation remains available for exceptional cases.
