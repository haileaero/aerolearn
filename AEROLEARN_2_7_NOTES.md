# AeroLearn 2.7 — Academic Operations Suite

This release focuses specifically on Attendance and the pages below it in the sidebar.

## Attendance rebuilt
- Removed the old oversized gradient hero and large summary cards.
- New compact Academic Operations header and five-step workflow ribbon.
- Session setup is now a dense 6-field control row.
- Recent attendance sessions are shown as compact week/period history chips.
- Live Students / Present / Absent / Late / Attendance Rate metrics.
- Replaced the large status dropdown with quick Present / Absent / Late segmented controls.
- Added one-click Mark All Present.
- PDF export remains available.
- Save/update attendance is presented in a compact save bar.
- Empty-state guidance when no register is open.

## Assessment workflow
- Create Assessment, Submit Scores and View Results now visually belong to the same connected Academic Operations workflow.
- Added a consistent step ribbon so users can understand the sequence Attendance → Assessment → Scores → Results → Resources.

## Sidebar
- Courses remain under Academic.
- Attendance and the lower workflow now have their own Academic Operations section.
- Assessment submenu remains expanded while a user is inside any assessment route.

## Learning Materials
- Added an Add Material / Close control so the upload form is no longer permanently visible.
- Editing automatically opens the material form.
- Added compact resource type filters: All, Lecture Note, Assignment, Exercise, Slides, Video, Other.
- Added the connected operations ribbon.

## Announcements
- Publishing form is now collapsible.
- Added compact priority filters: All, High, Normal, Low.
- Editing opens the composer automatically.
- Header actions and counts are now compact and consistent with other control-center pages.

## Profile
- Tightened profile header, panels, information blocks and password fields to match the compact visual system.

## Verification
- Changed lower-sidebar files: ESLint passes with 0 errors.
- Backend JavaScript syntax validation passes.
- No database schema changes.
- Existing APIs and core workflows are preserved.
