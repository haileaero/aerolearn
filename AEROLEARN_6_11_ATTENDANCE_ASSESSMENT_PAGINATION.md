# AeroLearn 6.11 — Attendance and Assessment Pagination

- Attendance class register displays 20 students per page while preserving the full roster and all selected attendance statuses.
- Attendance status changes still update the correct student across pages; mark-all-present and PDF actions continue to apply to the complete roster.
- Assessment score entry supports pagination over the filtered student roster, while search and section filtering continue across the entire roster.
- Assessment results also paginate independently.
- Pagination resets when opening a new attendance register or assessment, and when changing score search/section filters.
- Added responsive shared pagination styling.
