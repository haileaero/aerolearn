# AeroLearn 4.2 — Resource Studio

Learning Materials was redesigned into a compact professional Resource Studio.

## Improvements
- Replaced oversized uneven material cards with balanced responsive resource cards.
- Added a structured search + course selector command bar.
- Added compact category chips and live result count.
- Video resources receive a dedicated visual preview treatment.
- Documents, notes, assignments, exercises, slides and other resources each receive a clear visual identity.
- Long descriptions are clamped so one resource cannot dominate the page.
- Course name/code is visually separated from the resource title.
- Due dates are highlighted cleanly for assignments/exercises.
- Resource actions are compact and consistent with the rest of AeroLearn.
- Added a proper empty state.
- Mobile/tablet layout improved.
- Footer version updated to v4.2 where applicable.

This release changes the client only; the current server can remain unchanged.
