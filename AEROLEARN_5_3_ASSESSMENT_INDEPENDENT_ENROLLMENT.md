# AeroLearn v5.3 — Assessment creation independent of enrollment

- Admin and Instructor can create an assessment for a valid course even when no students are currently enrolled.
- Existing enrolled/matching students are still added to the initial score sheet when available.
- When no students are available, the assessment is created with an empty score sheet instead of returning an error.
- Existing later enrollment/result repair behavior remains available for students added after assessment creation.
- Assessment form now explicitly states that student enrollment is not required.
