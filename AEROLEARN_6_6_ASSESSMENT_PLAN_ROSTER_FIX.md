# AeroLearn v6.6 — Assessment Plan & Roster Fix

- Score sheets synchronize with the complete active registered class roster for the course while preserving existing marks.
- Newly registered matching students are added automatically; removed/inactive students are no longer shown.
- Removed the obsolete Custom assessment action and form.
- Top KPI now counts reusable Assessment Types rather than individual components.
- Course assessment plans now have Manage and Delete actions.
- Deleting a course plan removes that course's assessment components/scores but keeps reusable assessment types, allowing immediate reassignment.
